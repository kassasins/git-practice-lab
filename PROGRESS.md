# Progress tracker

Check off challenges as `./scripts/verify.sh NN` passes.

## Level 1 · Foundations

- [ ] **01** First commit — stage and commit files cleanly
- [ ] **02** Ignore secrets — stop tracking what should stay local
- [ ] **03** Fix the last commit — message and content without rewriting history wrongly
- [ ] **04** Undo safely — unstage, discard, and recover intent

## Level 2 · Branching

- [ ] **05** Feature branch — branch, commit, merge back
- [ ] **06** Merge conflict — resolve and finish the merge
- [ ] **07** Cherry-pick — bring one commit across branches
- [ ] **08** Rebase — linearize a feature branch onto main

## Level 3 · Remotes

- [ ] **09** Talk to origin — fetch, pull, push
- [ ] **10** Diverged history — reconcile local and remote
- [ ] **11** Tags and a release — annotate and point correctly
- [ ] **12** Collaboration simulation — PR-style branch hygiene

## Level 4 · Recovery

- [ ] **13** Detached HEAD — get back on a branch with your work
- [ ] **14** Lost commit — recover from reflog
- [ ] **15** Stash debt — apply stash and clear the mess
- [ ] **16** Bisect — find the bad commit

## Level 5 · Advanced

- [ ] **17** Linked worktree — fix or use a second checkout
- [ ] **18** Line endings — make status clean with attributes
- [ ] **19** Hook trap — unblock commits without disabling safety forever
- [ ] **20** Ref cleanup — remove forbidden backup refs

---

**Tip:** After each pass, write one sentence in your own words: *what broke* and *what fixed it*. That turns practice into lasting skill.
